# Validação de Entrada de Dados e Sanitização

<div>
  A Validação de entrada de dados é uma forma de minimizar as chances de pessoas má intencionadas acessarem informações do banco de dados. Essa é uma técnica que deve ser implementada no backend ou no frontend da aplicação e serve para evitar ataques como o SQL Injection.
</div>


A <a href="https://mapel.com.br/sanitizacao-de-dados/" target="_blank">sanitização</a> por outro lado é uma técnica para eliminar ou tornar irrecuperáveis informações dos bancos de dados com o objetivo de atender requisitos de privacidade dos dados. Um exemplo de uso é quando o CPF ou número do cartão de crédito do usuário tem parte dos números ocultados para evitar que outra pessoa utilizem esses números.
