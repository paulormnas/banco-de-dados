# Criptografia de Dados Sensíveis

<div>
  Um prática muito importante é criptografar dados sensíveis como senha, chaves de API e variáveis de ambiente que são importantes para o funcionamento do sistema. Esses dados devem ser criptografados sempre que os dados sensíveis são armazenaods no no banco de dados. 
</div>

Por exemplo, uma boa prática com senhas de usuários é armazenar um hash criptográfico da senha de maneira que, caso as senhas vazem algum dia, o atacante não consiga recuperar a informação original.
