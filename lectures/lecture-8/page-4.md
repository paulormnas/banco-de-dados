# Normalização

<div class="text-justify">
Existem casos em que aplicar a normalização pode penalizar o desempenho do Banco de Dados, tendo em vista que as consultas devem acessar diversas tabelas para compor uma única informação, como é o caso de <span class="italic">Business Intelligence</span> (BI). Neste tipo de aplicação é desejável analisar dados de diversas fontes para montar gráficos e facilitar a tomada de decisão de uma empresa. Se os dados estão espalhados em muitas tabelas, se torna computacionalmente custoso realizar qualquer tipo de consulta que retorne uma quantidade grande de dados.
</div>
