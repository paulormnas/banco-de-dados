# Relações

<div>
As relações entre tabelas são conexões lógicas que estabelecem como os dados em diferentes tabelas de um banco de dados se relacionam entre si. Essas relações garantem a integridade dos dados, evitam redundâncias e permitem consultas eficientes entre múltiplas tabelas.
</div>

Em um banco de dados relacional, as tabelas não existem isoladamente. Elas se conectam através de chaves primárias (PK) e chaves estrangeiras (FK). Uma chave primária identifica unicamente cada registro em uma tabela, enquanto uma chave estrangeira referencia a chave primária de outra tabela, criando assim uma ligação entre elas.

Existem três tipos principais de relações: one to one, one to many e many to many. Nesta aula, focaremos nos dois tipos mais comuns: one to many e many to many.
