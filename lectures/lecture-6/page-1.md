# MySQL Workbench e Diagram de Entidades

<div>
No Workbench vamos usar a ferramenta de geração de diagrama de entidades. Esta ferramenta nos permite gerar schemas de forma mais prática conectando as tabelas e reorganizando a figura apenas com Drag and Drop. A figura do próximo slide apresenta esta ferramenta do Workbench.
</div>

Quando estamos criando diagramas que representam o banco de dados nos referimos a cada tabala como uma representação de uma entidade do mundo físico. Por exemplo, considerando que temos que montar um banco de dados que auxilieno controle de empréstimos de livros de uma biblioteca nos podemos pensar nas seguintes entidades:

- Livro
- Aluno
